# India COVID-19 State-Wise Vaccination Dashboard


## 📌 Project Overview
This Power BI dashboard provides a simple and interactive visual analysis of India's COVID-19 vaccination drive. Utilizing official state-wise data, it tracks immunization progress, dose distribution, and demographic trends across all Indian States and Union Territories.

## 🚀 Key Features
* **State-Wise Map:** Visual breakdown of vaccine distribution across India.
* **Dose Metrics:** Clear tracking of Total Doses, First Doses, Second Doses, and Precautionary Doses.
* **Demographics:** Insights into vaccination by States.


## 🛠️ Data Source & Tools
* **Data Source:** Official [CoWIN Dashboard](https://cowin.gov.in) dataset.
* **Tool Used:** Microsoft Power BI Desktop.
* **Data Prep:** Power Query & DAX for calculations.

## ⚙️ How to Open the Project
1. Download or clone this repository.
2. Download and install **Power BI Desktop** (Free).
3. Open the `.pbip` file included in this repository.
